# 「判斷」與「Switch」合併為一種 Choice node；MVP 只由觀看者點選

**選了什麼**
- Node 只有四種：`Start`、`Scene`、`Choice`、`End`。`Choice` 有 2～N 個出口，是／否就是兩個出口。
- MVP 的分支條件只有「觀看者自己點選」。Chiao 在 2026-10-18 選定。

**沒選什麼、為什麼不選**
- 判斷（bool）與 Switch 分成兩種 node：功能重疊，node 種類越多，編輯器越難學、播放器越難寫。
- MVP 就支援變數條件（看過哪個畫面、隨機等）或觀看者輸入文字：範圍大幅擴張，延後到第二階段，**不是否決**。
  輸入文字（名字、暗號）很有「傳訊息」感，第二階段優先評估。

**如果錯了會怎樣**
- 若製作者需要「不經觀看者選擇的自動分支」，要加條件 node。資料格式的 node 型別是可擴充的列舉，加型別不需要改既有 node。
