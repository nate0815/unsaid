# 先做視覺 spike 與匯出，再做流程編輯器

**選了什麼**
- 順序是 M1 視覺 spike → M2 播放器＋匯出 → M3 流程編輯器 → M4 Scene 編輯面板。
- M1 沒通過 H1（效果打不打動人），就停在 M1 調整，不往下做。

**沒選什麼、為什麼不選**
- 先做流程編輯器：它的工程量最大，卻最沒有不確定性（React Flow 照著用就做得出來）。
  真正不確定的是「畫面夠不夠打動人」和「單一 HTML 交付通不通」，這兩件該最先回答。

**如果錯了會怎樣**
- 成本很低：M1、M2 的產物（轉換、播放器、匯出）都會被 M3 之後直接沿用，不是丟棄式的。
