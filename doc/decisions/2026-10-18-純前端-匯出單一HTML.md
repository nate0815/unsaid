# 純前端，交付方式是匯出單一 HTML

**選了什麼**
- 工具本體是純靜態網站，放在 GitHub Pages，沒有後端。
- 製作者完成後「一鍵匯出」單一 HTML 檔（播放器＋專案資料內嵌），自己傳給對方；離線可開。

**沒選什麼、為什麼不選**
- 後端＋分享連結：GitHub Pages 只能放靜態檔；訊息會存在第三方伺服器；伺服器停了訊息就全部失效。
  唯一優點是傳連結比傳檔案方便。
- 完整比較見 [PLAN.md](../PLAN.md)「為什麼不用線上分享連結」。

**如果錯了會怎樣**
- 若觀看者普遍打不開 HTML 附件（例如通訊軟體擋檔案、手機不會開本機 HTML），交付方式要改。
  H2 驗證時要特別看手機上「收到檔案 → 打開」這一步。
