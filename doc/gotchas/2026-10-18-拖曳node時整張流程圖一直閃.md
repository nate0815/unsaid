# 拖曳 node 時整張流程圖一直閃

**現象**
- 在流程編輯器拖曳任何 node，畫面一直閃。拖曳、連線都照常能用，沒有任何錯誤。
- 用 headless Chrome 量：拖曳一次（20 步），node 被設成 `visibility: hidden` **131 次**。

**原因**
- 編輯器只有一份 `Project` 狀態，每次重繪都從它重建 React Flow 的 node 物件，而且沒帶 `measured`。
- React Flow 12 的 `adoptUserNodes` 看到新物件就用 `userNode.measured` 建內部 node，同時把 `handleBounds` 清掉
  （原始碼註解：「removes `measured` … so that the node gets re-measured」）。
  沒有尺寸的 node 會先被隱藏、量完才顯示 —— 拖曳時每一格都重繪，每一格都閃一次。

**解法**
- 在 `onNodesChange` 把 `dimensions` 變更記進一個 ref（`measured`），建 node 物件時帶回去。修完同一個測試量到 0 次。
- 寫成 TECH「不變式」#17。
