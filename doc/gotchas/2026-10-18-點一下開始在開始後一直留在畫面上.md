# 「點一下開始」在開始之後一直留在畫面中央

**現象**
- 匯出檔或預覽裡按下開始後，Scene、Choice、End 都正常，但「點一下開始」四個字一直疊在畫面中央。
- 檢查 DOM，那顆按鈕的 `hidden` 屬性確實是 `true` —— 自動檢查只看這個屬性，所以報告「已隱藏」。

**原因**
- `.u-start` 的 CSS 寫了 `display: grid`。作者樣式的 `display` 會蓋過瀏覽器內建的 `[hidden] { display: none }`，`hidden` 屬性就失效了。

**解法**
- 播放器 CSS 加 `.u-root [hidden]{display:none!important}`（TECH「不變式」#13）。
- 檢查「有沒有顯示」要看 `getComputedStyle(el).display`，不要看 `hidden` 屬性。
