# Unsaid

**把說不出口的話，做成一段 ASCII 字元演出，匯出成一個 HTML 檔交給對方。**

製作者用流程圖把一個個字元畫面串起來 —— 上傳圖片轉成字元、換成自己的字句、加上特效、讓對方做選擇 ——
最後一鍵匯出單一 HTML，對方雙擊就能看，不需要網路。純前端，你的圖片與文字不會離開你的瀏覽器。

---

## 怎麼跑起來

需要 Node.js 22 以上。

**Windows：雙擊根目錄的 `start.bat`。** 第一次會先安裝套件（要網路），之後瀏覽器會自動打開。關掉那個黑色視窗就停止。

或用終端機：

```bash
npm install
npm start          # 等同 npm run dev，但會自動開瀏覽器
```

看到一顆由「有些話我一直沒有說出口……」這句話填成的心，就是跑起來了（網址通常是 `http://localhost:5173/`）。

**用手機看**：`npm run phone`，手機連同一個 Wi-Fi，打開它印出的 `Network:` 那個網址。
這會讓同一個網路裡的其他裝置也連得到，用完記得關掉。
把自己的圖拖進畫面，或用左邊的拉桿調參數。

**線上版**：https://nate0815.github.io/unsaid/ —— 推到 `main` 會自動測試、建置並部署（`.github/workflows/pages.yml`）；
開 PR 時只跑測試與建置，當作合併前的檢查。
