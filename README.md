# Unsaid

**把說不出口的話，做成一段 ASCII 字元演出，匯出成一個 HTML 檔交給對方。**

製作者用流程圖把一個個字元畫面串起來 —— 上傳圖片轉成字元、換成自己的字句、加上特效、讓對方做選擇 ——
最後一鍵匯出單一 HTML，對方雙擊就能看，不需要網路。純前端，你的圖片與文字不會離開你的瀏覽器。

---

## 怎麼跑起來

需要 Node.js 22 以上。

**Windows：雙擊根目錄的 `start.bat`。** 第一次會先安裝套件（要網路），之後瀏覽器會自動打開。關掉那個黑色視窗就停止。

或用終端機：

```bash
npm install
npm start          # 等同 npm run dev，但會自動開瀏覽器
```

看到**流程編輯器**（畫布上有「開始 → Scene → 結尾」三個方塊）就是跑起來了（網址通常是 `http://localhost:5173/`）。
右上角「Scene 工作室（試作）」是調參數的試作頁（`/spike.html`）。

**用手機看**：`npm run phone`，手機連同一個 Wi-Fi，打開它印出的 `Network:` 那個網址。
這會讓同一個網路裡的其他裝置也連得到，用完記得關掉。
把自己的圖拖進畫面，或用左邊的拉桿調參數。

**線上版**：https://nate0815.github.io/unsaid/ —— 推到 `main` 會自動測試、建置並部署（`.github/workflows/pages.yml`）；
開 PR 時只跑測試與建置，當作合併前的檢查。

## 現在到哪了

- **狀態**：實驗型 prototype，2026-10 起。M1 視覺 spike 可以玩：圖片轉字元（密度模式、訊息填充模式、中文全形）、純文字、四種特效；
  可以讀 GIF 動圖，也可以把畫面（含特效）匯出成 GIF 或 PNG。
- **流程編輯器（M3）**：拖拉 node、連線、編輯屬性；Scene 可以用文字、圖片或 GIF；沒接好的地方會標紅並擋下匯出；自動存在這台瀏覽器；可預覽、匯出單一 HTML、下載／匯入專案檔（匯出的 HTML 也能匯入取回）。
- **還不能做什麼**：Scene 的完整調參（輪廓、特效強弱）與逐格手修 —— 那是 M4；目前完整調參在 Scene 工作室（試作）。
- **正在驗證**：製作者不碰 JSON，只用編輯器就能做完一則訊息（[doc/DESIGN.md](doc/DESIGN.md)「要驗證的假設」H3，M4 完成後判定）。
